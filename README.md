# Book_Store_Analysis
PostgreSQL Bookstore Database Project | SQL queries, data analysis, joins, aggregations, and customer/order insights.


This project is a PostgreSQL-based Bookstore Database created to practice SQL and database management concepts.

The database contains three main tables: **Books, Customers, and Orders**. SQL queries are used to analyze book inventory, customer orders, sales, revenue, and purchasing patterns.

# 🛠️ Technologies Used

- PostgreSQL
- SQL
- pgAdmin
- CSV

# 📊 SQL Concepts Used

- SELECT and WHERE
- ORDER BY and LIMIT
- DISTINCT
- BETWEEN
- JOIN
- GROUP BY
- COUNT(), SUM(), AVG()
- Aggregate functions
- Data filtering and analysis

# 🔍 Key Analysis

The project includes queries to:

- Find books by genre and publication year
- Analyze book stock and prices
- Calculate total revenue
- Find the most frequently ordered books
- Analyze sales by genre and author
- Identify customers with multiple orders
- Find customers with the highest spending

# 🎯 Learning Outcome

This project helped me gain practical experience in PostgreSQL, relational databases, SQL queries, table relationships, data aggregation, and basic data analysis.
